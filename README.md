# 🍯 HoneyTrace v2.0

## AI Powered Honeypot & Threat Intelligence Platform

HoneyTrace is an AI-powered cybersecurity platform designed to detect unauthorized SSH login attempts using an intelligent honeypot. It captures attacker information, stores stolen credentials, performs AI-based threat analysis, visualizes attacks on an interactive world map, and generates professional PDF investigation reports.

---

## Features

- SSH Honeypot
- Attacker Profiling
- Credential Capture
- AI Threat Analysis
- Interactive Attack Map
- PDF Investigation Reports
- Spring Boot Dashboard
- Real-Time Monitoring
