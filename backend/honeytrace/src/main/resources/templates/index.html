About HoneyTrace

HoneyTrace is an AI-powered cybersecurity platform designed to detect malicious SSH login attempts using an intelligent honeypot. The system records attacker behaviour, captures usernames and passwords, analyses threats using Artificial Intelligence, visualizes attack locations on an interactive world map and generates professional PDF investigation reports.

Getting Started

  1. Start the HoneyTrace SSH Honeypot server.
  2. Perform an SSH login attempt from another device.
  3. Open Attackers to monitor detected attackers.
  4. View captured usernames and passwords in Credentials.
  5. Analyse attacker behaviour using AI Analysis.
  6. Visualize attack locations in Attack Map.
  7. Generate a professional investigation report from Reports.
Tip: All HoneyTrace modules are available from the left sidebar.
